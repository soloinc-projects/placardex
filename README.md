# Placardex — website

The public website of Placardex, an offline reference to the U.S. Hazardous Materials Table (49 CFR §172.101) and
the §177.848 segregation table, by 8086 LLC: the landing page, the privacy policy, support and the terms of use.
This repository holds only the site's files; the app's code is kept in its own private repository.

Served by GitHub Pages from `main`, root: https://soloinc-projects.github.io/placardex/

- `index.html`, `privacy/`, `support/`, `terms/`: the pages. Links are relative, so they work under `/placardex/`.
- `assets/site.css`: the shared style, in the brand's light and dark colour tokens.
- `fonts/`: Barlow Bold and IBM Plex Mono Regular, unmodified, under the SIL Open Font License 1.1 (licences beside
  them).
- `screenshots/`: renders of the app's designed screens; replaced by the built app's own screenshots before release.

Placardex is not a government app and is not affiliated with or endorsed by any government agency.
